Nerd Utility API

Free. No API key. No signup. Fast micro-utilities for developers and AI agents.

curl "BASEURL/hash?algo=sha256&value=hello"

Endpoints

/format — pretty/minify/validate JSON & CSV: ?type=json&mode=pretty&value=...
/csv2json — convert CSV to JSON: ?value=a,b,c%0d1,2,3
/json2csv — convert JSON array to CSV: ?value=[{"a":1}]
/hash — md5, sha1, sha256, sha512: ?algo=sha256&value=hello
/base64 — encode/decode: ?mode=encode&value=hello
/uuid — generate UUIDv4 (pass ?count=10 for batch)
/timestamp — unix <-> ISO conversion, plus relative dates
/validate — email|url|ipv4|ipv6|json|uuid|luhn checks
/weather — current + forecast: ?city=London or ?lat=&lon=
/whois — domain registration via RDAP: ?domain=example.com
/shorten — URL shortener: ?url=https://... → /s/<code> redirect
/rss — any RSS/Atom feed to JSON: ?url=<feed>&limit=10
/qrcode — PNG QR codes: ?value=hello&size=300
/dns — A/AAAA/MX/TXT/CNAME lookups: ?domain=example.com&type=A
/headers — echo your request headers as JSON
/price — crypto prices: ?coin=bitcoin&vs=usd
/ipinfo — IP geolocation: ?ip=8.8.8.8 or auto-detect
/scrape — fetch page → clean text/links/title: ?url=...
